# Nexus Studio • Developer & Indie Software Portfolio

An interactive, modern developer portfolio website showcasing desktop tools, Android applications, browser extensions, and experiments.

## ✨ Highlights
- **Interactive UI Sandbox:** Interactive simulators for ScreenShield, OmniClean benchmarks, and procedural Balatro cards.
- **Modern Glassmorphic Design:** Smooth dark/light aesthetics with ambient particle effects and responsive typography.
- **Tech Stack:** HTML5, CSS3 (Modern Flex/Grid & Custom Properties), Vanilla JavaScript (Modular ES6+).

## 🚀 Live Demo & Usage
Simply open `index.html` in any modern web browser or serve via GitHub Pages.
